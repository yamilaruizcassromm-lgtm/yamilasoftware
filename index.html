Introducción

En este trabajo práctico se analiza el material audiovisual sobre Supabase, un servicio de Backend as a Service (BaaS) de código abierto basado en PostgreSQL. A lo largo del documento se detallan las respuestas al cuestionario planteado, los conceptos clave comprendidos y una implementación práctica integrando Supabase con desarrollo web estándar.

Conceptos Fundamentales

BaaS

Backend as a Service: plataforma que administra la infraestructura de base de datos y servidor en la nube.

PostgreSQL

Base de datos relacional potente de código abierto que sirve de motor principal para Supabase.

REST API

Interfaz autogenerada por la plataforma para consultar datos mediante métodos HTTP estándar.

RLS

Row Level Security: mecanismo para restringir las filas que un usuario puede consultar o modificar.

Cuestionario Resuelto (12 Preguntas)

  1. 1. ¿Cuál es el tema principal del video? Explica de qué trata.

    El tema principal es Supabase, una plataforma Backend as a Service (BaaS) de código abierto que actúa como alternativa a Firebase, permitiendo crear bases de datos en la nube y acceder a ellas vía REST API.

  2. 2. ¿Qué problema o necesidad tecnológica se aborda?

    Resuelve la complejidad de tener que programar y mantener un servidor backend completo desde cero para gestionar datos y autenticación en aplicaciones web o móviles.

  3. 3. ¿Cuáles son los cinco conceptos más importantes? Define cada uno.

    BaaS (Backend como servicio), PostgreSQL (motor de base de datos), REST API (endpoints autogenerados), Anon Key (clave de acceso seguro en cliente) y RLS (seguridad por filas).

  4. 4. ¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

    Supabase Dashboard (administración de proyectos), PostgreSQL (gestión relacional), JavaScript/Supabase SDK (conexión desde el frontend) y REST Client en VS Code (prueba de endpoints HTTP).

  5. 5. ¿Qué procedimientos o pasos se explican? Preséntalos en orden.

    1. Crear proyecto en Supabase. 2. Diseñar la tabla en el SQL Editor/Dashboard. 3. Insertar registros. 4. Obtener URL y Anon Key. 5. Conectar y realizar peticiones desde la app cliente.

  6. 6. ¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

    La creación de una tabla de tareas o productos, definiendo tipos de datos como textos y booleanos, e insertando filas para luego consultarlas mediante formato JSON a través de una petición GET.

  7. 7. ¿Qué conocimientos previos son necesarios para comprender lo explicado?

    Conceptos básicos de HTML, JavaScript, sintaxis básica de consultas SQL y principios de funcionamiento del protocolo HTTP/REST.

  8. 8. ¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

    Acelera sustancialmente el desarrollo, elimina la necesidad de configurar servidores manuales, utiliza un estándar abierto (PostgreSQL) y genera las APIs automáticamente.

  9. 9. ¿Qué dificultades, errores o precauciones deben considerarse?

    Tener cuidado con la exposición accidental de claves de servicio y configurar adecuadamente las políticas de seguridad RLS para evitar bloqueos de peticiones.

  10. 10. ¿Cómo aplicarías lo aprendido en un proyecto informático real?

    Desarrollando una aplicación web interactiva que almacene datos de usuarios de manera persistente en la nube mediante peticiones asíncronas a Supabase.

  11. 11. ¿Qué parte del video consideras más importante y por qué?

    La integración de la base de datos con las peticiones REST y las API Keys, ya que demuestra la rapidez con la que se pasa de una tabla de base de datos a un consumo de datos real.

  12. 12. ¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

    Entendí cómo funcionan los servicios BaaS. Explicaría que Supabase es una herramienta que nos exime de programar un servidor completo al ofrecernos una base de datos con API lista para usar.
